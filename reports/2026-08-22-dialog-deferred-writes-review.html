What was under review

An uncommitted diff across five files: dev-script swap to portless, focus({preventScroll}) in the calendar, controlled calendar popovers in ProjectCard/TaskDetails, and a rework of subtask editing plus deferred post-unmount writes in TaskDetails.

Review verdict on the original diff

  • Blocker 1: clicking Done with a focused, renamed subtask lost the rename on Chrome/Firefox. armClose armed closingRef on pointerdown (suppressing the input's deferred blur write), but captureFocusedSubtask ran at click time when document.activeElement had already moved to the button.
  • Blocker 2: Archive silently discarded unsaved title/notes edits — a regression against HEAD, where the blur commit ran before close.
  • No perf regressions found; the change is a net win (zero renders per keystroke in subtask drafts, preventScroll fixes ancestor scroll jumps).
  • Minor notes: uncontrolled inputs go stale on remote renames while the dialog is open; README still documents localhost:3000 after the portless swap; render-phase ref writes are a concurrent-mode smell.

What changed (the fix)

All in src/tracker/board/TaskDetails.tsx:

  1. New PendingWrites type and pendingRef.
  2. collectPending() gathers fields + focused-subtask write + draft write in one place.
  3. armClose (pointerdown on Done/Archive) arms suppression AND captures into pendingRef. Pointerdown is the last event where focus has not yet moved to the button, so the captures see live values.
  4. closeWith(after?) consumes pendingRef (or collects inline for ESC/overlay), then in one setTimeout(0): subtask write, draft write, field commit, optional trailing action.
  5. Archive passes its mutation as the trailing action, restoring save-then-archive. Delete uses a new suppress-only armSuppress since its writes are moot.

Also fixed a stray extra brace in the Archive onClick left by an interrupted edit.
